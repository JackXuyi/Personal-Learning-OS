## 1. 背景

说明**为什么要做**这件事：

- 业务背景与用户痛点
- 触发原因（用户反馈、产品规划、技术债、合规等）
- 与现有产品/模块的关系
- 不做会有什么影响（可选）

## 2. 方案目标

| 类型 | 描述 |
|------|------|
| **主要目标** | 完成后用户/系统应达到的状态（可量化优先） |
| **非目标** | 明确本次**不做**的范围，防止范围蔓延 |
| **成功标准** | 验收条件清单（可测试、可观察） |

### 3.2 相关文档与约定

- 已阅读的 `docs/`、设计语言、API 文档链接
