## 1. 六类判据（先分类，再决定改不改）

| 类 | 定义 | 例子 | 处置 |
|----|------|------|------|
| **A 实现层描述** | 讲系统怎么做的 | 「SQLite 已在 src/storage 预留」「维度 384 · CPU 推理」 | **改**成讲结论 |
| **B 开发侧代号** | 开发者工作流语言 | 「Pre-MVP」「MVP 里程碑」「Workbench」「U6」 | **删或换**成用户语言 |
| **C 外部参数 / 协议常量** | 第三方真实字段名 | `Base URL`、`API Key`、日志级别 | **保留** |
| **D 用户要做的决定** | 用户据此行动 | 「导出前会自动备份」「切英文后下拉也变英文」 | **保留并写清后果** |
| **E 格式名 / 文件类型名** | 用户在文件选择器里见过的名字 | `Markdown`、`PDF`、`EPUB`、`TXT`、`OCR` | **保留** |
| **F 产品核心卖点** | 构成产品价值主张 | 「本地优先」（README 隐私章节） | **保留** |

> 🔴 **E / F 不可进黑名单**。它们是门禁恒红的最大来源——用户必须按原样识别这些词才能完成任务。

## 3. 句式规范

| 规范 | 规则 | 正例 |
|------|------|------|
| 讲后果不讲实现 | 说会发生什么 | 「关掉后导入的资料只按文字查找」 |
| 先结论后条件 | 条件从句后置 | 「这台设备不能做 OCR 识别（目前只有 macOS 桌面版支持）」 |
| 数字给口径 | 数值必带含义 | 「超过 50 页了，OCR 处理不了这么多页」 |
| 纯文本 UI 不用 Markdown | 禁 `**` `` ` `` | 「姓名与公司名不会自动打码」 |
| UI 不出现源码路径 | 禁 `src/…`、函数名 | 「已在内部预留好」 |
| 中文句子不夹英文技术词 | | 「纯文本」不是「纯文本（txt）」 |
| 错误文案给行动项 | 说什么 + 怎么办 | 「把 PDF 拆成几份再导入」 |
| en 侧母语化 | 不直译中文句式 | 「isn't ready yet」不是「is not ready」 |

## 4. 门禁对应关系

`scripts/copy-scan.mjs`（由 `scripts/settings-copy-scan.mjs` 演进）的黑名单**只取本表 §2「替换表」的技术说法列**，且遵守：

| 规则 | 理由 |
|------|------|
| **只扫值**（i18n 叶子），不扫键名 | 键名 `localStorageNote` / `errSqliteBlocked` 是标识符，会让门禁永远红着 |
| **不扫注释** | 注释里的禁用理由是工程信息，不是用户文案 |
| **排除 `src/ai/**`** | 那里的中文是 prompt，改它 = 改 AI 行为 |
| **只黑名单 §2 技术说法列** | E/F 类词不在列 ⇒ 门禁不会恒红 |
| 孤儿键**只报告不失败** | 与并行开发冲突，进台账不进 CI |
