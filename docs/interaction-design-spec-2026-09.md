## 0. 如何读这份文档

### 0.1 Wireframe 图例

```
[按钮]         可点击控件
(1) (2)        交互标注点，正文逐一说明其行为
█░░░           进度条（实心=当前值）
🡒             页面/流程跳转
<K1> <K2>      键盘快捷键
✅ ❌ ⚠️       状态徽标
【新】          本次新增或改动的模块 / 【原】现有模块复用
```

所有线框为文字示意，**间距与位置示意布局层级，不表示最终像素**；视觉沿用现有设计基线（白卡片 + slate 细边框 + indigo 主色 + rounded-xl，本地优先·极简风格），不做视觉翻新，只改信息架构与交互。

### 0.2 全局设计基线（所有页面共同遵守）

| 基线 | 规则 |
|---|---|
| 一屏一主行动 | 每屏只突出一个主 CTA（indigo 实底大按钮）；次级操作用文字链或灰底小按钮 |
| 反馈分级 | 操作即时反馈（按钮 loading / 禁用 ≤ 100ms）；结果反馈（对错、变化值）就地呈现；系统反馈（保存成功等）走右下角 Toast，2.5s 自动消失 |
| 状态可见 | 任何 > 800ms 的异步操作必须有进度指示（按钮 spinner 或面板内进度条），禁止静默等待 |
| 数字诚实 | 启发式引擎的掌握度步进（±0.08）展示为「变化徽标」，不伪装精确；间隔建议标注「启发式估计」 |
| 文案语气 | 对话式中文短句；不用「请」「您」等官腔；错误信息给出「原因 + 怎么办」 |
| 键盘流 | 桌面端（Tauri）所有高频动作有快捷键；复习会话与测评全键盘可达 |
| 不做操纵性设计 | 无连击/能量/排行/限时焦虑（见调研报告第七节护栏） |

### 0.3 导航信息架构（P2-4）

现状 7 项平铺 → 目标按「做什么」分组，弱化导航噪音：

```
【原】侧边栏
  首页 / 学习空间 / 知识 / 测评 / 职业 / 学习 / 设置   ← 平铺 7 项，无主次

【新】侧边栏（分组，非结构性改版）
  学习闭环          首页            ← 唯一「启动器」
  开始学习          学习            ← 今日队列 + 复习会话
                   测评            ← 自适应作答
  内容              知识            ← 图谱 + 导入
                   学习空间        ← 空间/资料库
  规划              职业            ← 目标就绪度（可并入首页，见 6.1）
  系统              设置
```

- 分组只做视觉分隔（小组标题），不改路由路径，不破坏现有链接。
- 「学习空间 / 职业」在 Phase 0.5 保持骨架页，入口保留但视觉降权。

## 1. 共享交互模块（先于页面落地，P0-1/P0-3 共同依赖）

> 调研报告依赖关系已指出：评分回写应先抽成共享 action。以下 M1–M4 是所有页面原型的公共地基。

### M1 · submitAnswer 统一评分回写（store action）

```
【数据流】
  作答/自评结果
      ↓
  submitAnswer(unitId, { correct?, rating? })      ← zustand action
      ↓
  applyEvaluation(...)         Learner Model 更新 mastery/认知层级/误解
  applyForgetting(...)         时间衰减修正
      ↓
  写回 storage (saveLearnerState)
      ↓
  refresh()                    重算 loop snapshot（就绪度/缺口/下一步）
      ↓
  返回 { masteryDelta, nextReviewInDays }          供 UI 展示变化徽标
```

| 项 | 规则 |
|---|---|
| 输入 | `unitId` + 证据（对错 `correct?: boolean` 或自评 `rating?: 'forget'\|'hard'\|'good'\|'easy'`，二者至少其一） |
| 输出 | `masteryDelta`（变化值，UI 做徽标）、`nextReviewInDays`（间隔建议，供「下次复习」提示） |
| 幂等 | 同一 evidence 只允许提交一次（ReviewSession 内锁定），防止双击双扣 |
| 依赖 | 复用 `src/engine/learner-model.ts`，不新写算法 |

### M2 · 掌握度变化徽标（P2-6）

```
(复习/作答提交后，单元行或详情处就地浮现)
  ┌─ 重排序 ───────────────────────┐
  │ 掌握度 43% ───────────────▶ 51% │
  │        (+0.08)  浮出 600ms 后淡入停留 │
  │ 下次复习：3 天后（启发式估计）      │
  └──────────────────────────────────┘
```
- 正值 indigo、负值 slate 红？——遵循「涨=积极」，本产品用色：上升 = indigo/emerald、下降 = red（对应用户中文习惯：掌握度升高用暖色正向、下降用警示）。
- 动画规格：数值滑入 600ms ease-out；若 +N 同时触发 BandBadge 档位变化，badge 换色时加 300ms 过渡。
- 数字诚实：徽标旁小字「启发式估计」；不显示到小数点后两位以上。

### M3 · Toast 规范（非阻塞系统反馈）

| 类型 | 样式 | 时长 | 用途 |
|---|---|---|---|
| 成功 | 右下角 emerald 描边 | 2.5s | 保存成功、导入完成 |
| 失败 | 右下角 red 描边 | 4s 或手动关 | 连接失败、抽取失败（含原因 + 处置建议） |
| 中性 | 右下角 slate | 2s | 无实质反馈的轻提示 |

Toast 不承载主流程关键反馈——对错/评分结果必须在内容区就地呈现，不走 Toast。

### M4 · 空状态规范（P2-5）

统一四件套：**图示（emoji/图标）+ 一句话说明 + 主行动按钮 + 次行动文字链**。各页空态文案见各节 wireframe。

## 2. S0 · 首页（P0-2 主 CTA + P2-3 目标梯度 + P2-5 空态）

### 2.1 目标

把首页从「数据看板」改成「每日启动器」：首屏唯一任务 = 看到今天该做的一件事并点下去。

```

│  当前目标 · AI 应用工程师 · 职业 · 重要性 高 【原】               │
│                                                                 │
│  就绪度  ████████░░░░░░░░░░░░  33%         目标 80% ▏ (2)       │
│  还差 2 个单元达标：重排序(+47%) · 评估(+21%)    (3)             │
│                                                                 │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  (4)  ▶ 开始今天的下一步                       (5)        │  │
│  │      复习 · 重排序                                       │  │
│  │      ──────────────────────────────────────────          │  │
│  │      ▸ 为什么是它？（点击展开）                           │  │
│  │        1. 它是「向量检索」的前置依赖，缺口会阻塞下游        │  │
│  │        2. 当前掌握度 43%，距 80% 达标还差 37%              │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
│  学习计划（4 项 · 依赖序）  →  查看全部  (6)                      │
│  01 [复习] 重排序    ████░ 43%  学习中                           │

│  03 [练习] 分块      ███░░ 61%  较熟练                           │
└────────────────────────────────────────────────────────────────┘

交互标注：

| # | 行为 |
|---|---|
| (1) | 右上角 ⌘K 入口按钮（Phase 0.5 先放图标位，P2-2 命令面板落地后生效） |
| (2) | Bar 增目标刻度线（80% 处竖线 + 标签「目标 80%」）；达标后刻度线变 emerald |
| (3) | 目标梯度拆解：列出距离达标最近的 2 个缺口及缺口值 —— P2-3 |
| (4) | **主 CTA**：大号 indigo 实底按钮。文案由 `next.kind` 驱动：复习→「开始今天的下一步」；学习→「开始学习」；测评→「去测评」。点击 🡒 `/study/session?unit=<id>`（kind=assessment 时 🡒 `/assessment?unit=<id>`） |
| (5) | 类型徽章 + 单元中文名 + 当前掌握度，让用户在点击前知道「做的是哪件事」 |
| (6) | 计划列表压缩为前 3 项 + 「查看全部」🡒 学习页；每项行尾 BandBadge 复用现有组件；点击列表项 = 对该单元开始同类型动作 |

## 3. S1 · 学习页 + 复习会话（P0-1 评分闭环 · 本阶段最重模块）

### 3.1 目标

把「学习」页从占位变成闭环执行点：**今日队列 → 复习会话（先作答或自评）→ 四档评分 → 掌握度变化可见 → 自动下一项 → 完成汇总**。这是让 Home 主 CTA 真正转起来的执行面。

### 3.2 页面结构（学习页改为两级：队列页 /study ↔ 会话页 /study/session）

```
/study  队列页（今日总览）
/study/session?unit=<id>   复习会话（单单元一屏）
```

### 3.3 Wireframe — 队列页 /study

```
┌  学习 · 今日计划 ──────────────────────────────────────────────┐
│  目标：AI 应用工程师                                            │
│                                                                 │
│  今日复习队列（3 项 · 按推荐序）              [▶ 全部开始] (1)   │
│  ┌────────────────────────────────────────────────────────┐   │
│  │ 1 [复习] 重排序   学习中 43%   上次 2 天前 · 建议今天   ▶  │  │
│  │ 2 [学习] 检索     未开始  0%   新内容                  ▶  │  │
│  │ 3 [练习] 分块     较熟练 61%   上次 5 天前 · 可延后     ▶  │  │
│  └────────────────────────────────────────────────────────┘   │
│  每项行尾 ▶ 进入该单元会话；灰字为间隔建议（启发式） (2)        │
│                                                                 │
│  今日已完成（2）                      (3)                        │
│  ✓ 向量检索  +0.06 · 下次 3 天后        ✓ 智能体  +0.10 · 已达标 │
│                                                                 │
│  无待办时：                                                        │
│  ┌──────────────────────────────────────────────┐              │
│  │ 🎉 今日队列已清空                              │              │
│  │ [去测评巩固]（→/assessment）· [查看计划]       │              │
│  └──────────────────────────────────────────────┘              │
└────────────────────────────────────────────────────────────────┘
```

| # | 行为 / 规则 |
|---|---|
| (1) | 全部开始 🡒 依次进入队列第 1 项会话；每项完成自动 push 下一项 |
| (2) | 间隔建议来源：`nextReviewInDays` 启发式（M1 输出），不足 = 诚实标注「启发式估计」；「可延后」表示已过最佳复习窗的单元，仍可点但视觉降权 |
| (3) | 「今日已完成」按时间倒序，含变化徽标（M2）与下次复习日；清空按钮供演示重置 |

| # | 行为 / 规则 |
|---|---|
| (1) | 变化徽标 = M2。下降（忘记）时红色「−0.15」并附安抚文案「没关系，间隔缩短到 1 天，明天再来」——不羞辱、不惩罚（护栏） |

| (3) | 撤销窗口 5s：调 storage 回滚该 evidence（仅在会话内有效，刷新后不可撤销） |

```
┌  本次复习完成 🎉 ──────────────────────────────────────────────┐

│                                                                 │
│  掌握度变化：                                                     │
│   重排序   43% → 55%  (+0.12)     记得                            │
│   检索     0% → 28%   (+0.28)     新学                           │
│   分块     61% → 66%  (+0.05)     困难                            │
│                                                                 │
│  就绪度 33% → 41%（目标 80%）                                     │
│  ██████████░░░░░░░░  41%                                        │
│                                                                 │
│  [回到首页]   [继续测评巩固 →]                                     │
└────────────────────────────────────────────────────────────────┘
```
- 「回到首页」🡒 `/`（首页就绪度自动刷新，用户看到自己操作的结果）。
- 汇总数据 = 本次会话 evidence 列表；不新增持久化结构。

### 3.7 状态机（会话页）

```
[队列页] --点项/全部开始--> [展示态]
[展示态] --显示要点--> [可评态]（可来回）

任意态 --退出--> [退出确认] --确认--> /study
```

## 4. S2 · 测评页（P0-3 最小作答循环）

### 4.1 目标

让 Assessment Engine 的本地降级路径可用：**从缺口取题 → 作答 → 即时对错 + 解释 → 写回 Learner Model → 再来一题**。一次「测一道」的最小循环，是让掌握度数字活起来的最低成本交互。

### 4.2 Wireframe — 测评首页（含空态）

```
┌  测评 ──────────────────────────────────────────────────────────┐
│  自适应题目 · 从你的缺口单元出题，难度随作答调整                   │
│                                                                 │
│  建议先测：重排序（学习中 43%）           [开始测评] (1)          │
│  或选择任意单元：                                               │
│  [重排序] [检索] [分块] [向量检索] [智能体]                      │
│                                                                 │
│  今日已测：2 题 · 全对 · 重排序 +0.06                            │
│  空态：还没有可测评的单元 → [去学习页] 先学一点再测               │
└────────────────────────────────────────────────────────────────┘
```

| # | 行为 |
|---|---|
| (1) | 「开始测评」🡒 进入作答屏；默认从 `snapshot.next` 单元取题，本地降级题库按 Bloom Remember→Understand→Apply 递进 |

### 4.3 Wireframe — 作答屏（答前 / 答后两态）

```

## 9. 设计护栏复核（实现时不越线）

1. 无连击/能量/排行/限时焦虑——复习失败文案只给「缩短间隔 + 明天再来」，无惩罚语言。
2. 一屏一主行动——会话页主操作只有「四档评分」一个；Home 首屏主操作只有主 CTA 一个。
3. 数字诚实——±0.08 步进与「3 天后/4 天后」一律带「启发式估计」小字。
4. AI 结论可溯源——抽取候选与图谱 Detail 必有 `sourceDocumentId` 回链，缺失则不展示该条。
5. 变化徽标颜色遵循掌握度语义：上升 emerald/indigo、下降 red，与掌握度 BandBadge 色系一致。
